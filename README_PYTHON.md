# متتبع عاداتي

تطبيق عربي بسيط لإدارة المهام اليومية والأسبوعية باستخدام Python وNiceGUI وSQLite.

## المميزات

- إضافة وتعديل وحذف المهام مع تأكيد قبل الحذف.
- ثلاث درجات أهمية وترتيب تلقائي للمهام غير المكتملة أولًا.
- إكمال المهمة مع حفظ `completed_at` وتحديث النسبة والإشعارات.
- اختيار يوم من الأسبوع وعرض مهامه المرتبطة بالتاريخ.
- تقييم الأسبوع، أفضل وأسوأ يوم، ومتوسط الإنجاز وعدد الأولويات العالية المكتملة.
- واجهة عربية RTL، حالات فارغة، تحقق من الإدخال، وتسجيل أخطاء التشغيل.
- حساب مستقل لكل مستخدم مع تسجيل دخول وإنشاء حساب وتسجيل خروج.
- تذكير تلقائي بعد 4 ساعات من إضافة المهمة، ورسالة تحفيز بعد إكمالها.

## المتطلبات

- Python 3.11 أو أحدث، ويعمل مع Python 3.14 عند توفر إصدار NiceGUI متوافق.
- Windows أو أي نظام يدعم Python.

## التثبيت والتشغيل

```powershell
python -m pip install -r requirements.txt
python main.py
```

افتح `http://localhost:8080` في المتصفح.

## الاستخدام

أنشئ حسابًا أو سجّل الدخول، ثم أضف مهمة من زر «إضافة مهمة»، واختر مستوى الأهمية والتاريخ. استخدم مربع الاختيار لإنهائها. يمكن تعديل المهمة أو حذفها من أزرار الصف. لكل مستخدم مهامه وإحصائياته الخاصة، ولا تظهر مهام حساب داخل حساب آخر.

يبقى التطبيق يفحص مهام المستخدم كل دقيقة أثناء فتح الصفحة. بعد مرور 4 ساعات على إضافة مهمة غير مكتملة يظهر تذكير، وبعد إكمالها يظهر إشعار تحفيزي مرة واحدة. يجب إبقاء صفحة التطبيق مفتوحة لاستقبال الإشعارات.

## مشاركة التطبيق

للاستخدام من جهاز آخر، يجب أن يكون التطبيق والخادم الوسيط يعملين على جهازك. رابط المشاركة المؤقت الحالي هو:

`https://marcus-pleasant-cooper-hybrid.trycloudflare.com`

أرسل الرابط لصاحبك، وسيختار «إنشاء حساب» ليستخدم مهامه الخاصة. لا تغلق نافذة `cloudflared` أثناء الاستخدام؛ الرابط المؤقت يتوقف عند إغلاقها وقد يتغير عند إنشاء Tunnel جديد.

للاستخدام الحقيقي طويل المدى، استخدم استضافة أو Cloudflare Tunnel مُسمّى مع تسجيل دخول وحماية مناسبة.

## هيكل المشروع

- `main.py`: نقطة التشغيل وتهيئة NiceGUI.
- `database/db.py`: إنشاء SQLite وعمليات التخزين.
- `models/task.py`: نموذج المهمة.
- `services/task_service.py`: التحقق والإحصائيات ومنطق الأسبوع.
- `ui/`: مكونات الواجهة العربية RTL.
- `tests/test_tasks.py`: اختبارات منطق المهام.

يُنشأ ملف `habit_tracker.db` تلقائيًا بجانب `main.py` ويحفظ البيانات محليًا. يحتوي جدول `tasks` على رقم المهمة، الاسم، الأهمية، حالة الإكمال، وقت الإنشاء، وقت الإكمال، وتاريخ المهمة.
